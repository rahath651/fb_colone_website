# FB Clone Website

A front-end clone of Facebook's website, built as a hands-on project while learning Git and GitHub.

## About the Project

This project recreates the core look and layout of the Facebook website. It was built primarily as a learning exercise to practice using **Git** for version control and **GitHub** for hosting and collaboration — from making commits and writing commit messages, to pushing branches and managing a repository.

## Purpose

- Practice the Git workflow (init, add, commit, push, pull)
- Get comfortable using GitHub to host and manage a project
- Recreate a familiar, real-world UI to practice front-end structuring
- Build confidence before working on version-controlled team projects
